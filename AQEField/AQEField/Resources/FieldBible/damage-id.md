# Storm Damage ID (Field Gallery)

What qualifies, what doesn't, and how to document it. (Photo gallery
attaches in a later phase — this is the text key.)

## Hail — on shingles

- **Bruise:** dark round impact with displaced granules; mat feels soft
  like a bruised apple. Break one open: a fractured fiberglass mat proves
  impact. **Qualifies.**
- **Granule loss in impact pattern** — random distribution across the
  slope, not in drainage streaks. **Qualifies.**
- **Exposed asphalt shiny/black** = fresh; dull/gray = old. Adjusters know
  the difference — so should you.

## Hail — collateral (shoot these FIRST)

Soft metals corroborate hail size independently of the roof:
gutters, downspouts, gutter screens, window wraps/screens, AC condenser
fins, mailboxes, grills, fence caps, garage door panels.
Always include a scale reference (coin or hail gauge) in the photo.

## Wind

- **Creased shingles** — horizontal crease line where the tab folded back.
  Crease direction should match the storm's wind vector (NOAA event data).
- **Missing tabs/shingles** — photograph the exposed nail line.
- **Lifted/broken seals** — run a hand up the courses; broken seals are
  invisible from the ground but kill wind resistance.

## NOT storm damage (don't pitch it)

- **Blistering** — pea-sized pops with granules INTACT in the pit, no mat
  bruise. Manufacturing/heat issue.
- **Thermal cracking / crazing** — surface spider-webbing on aged shingles.
- **Foot traffic scuffs** — directional smears, usually near penetrations.
- **Nail pops & maintenance leaks** — repair work, not a claim.

Calling non-damage honestly is a sales weapon: "I'm not seeing qualifying
damage" earns the referral that IS a claim.

## Documentation standard (every inspection)

1. Address shot from the street.
2. All four elevations + collateral with scale reference.
3. 10x10 chalk test square per slope; circle every impact.
4. Close-ups: granule displacement + broken-open bruise.
5. Overview shot showing the test square in slope context.
