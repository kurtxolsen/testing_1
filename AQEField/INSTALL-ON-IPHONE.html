Get AQE Field onto your iPhone

The native app — with widgets, the Live Activity timer, and the full Field Bible — is built and in your repo. Here's how it gets from GitHub to your home screen.

First, the one hard rule: a real iPhone app can only be built on a Mac. Apple requires their toolchain (Xcode) to compile and sign it — there's no Windows, Linux, or website that can do this step. So everything below forks on that.

A You have a Mac

Three phases: install two free tools, build the app to the Simulator to confirm it works, then put it on your actual phone. Budget about 45 minutes the first time (most of it is Xcode downloading).

A1 · Install the two tools (one time)

  1. Xcode — open the Mac App Store, search Xcode, Install. It's big (~7 GB), so start it and go knock a few doors. When it finishes, open it once and click through the license prompt.
  2. Homebrew + XcodeGen — open the Terminal app (Cmd-Space, type "Terminal") and paste these one at a time:
# installs Homebrew (a tool installer) — it'll ask for your Mac password
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# then installs XcodeGen, which turns our project.yml into an Xcode project
brew install xcodegen

A2 · Get the code and build it

Still in Terminal, paste these. The last line builds the app to the iPhone Simulator — if it ends with Build succeeded, everything compiles.

# download the repo and step into the app folder
git clone https://github.com/kurtxolsen/testing_1.git
cd testing_1/AQEField

# generate + build + launch in the Simulator, in one command
./build.sh run
What you should see: the iPhone Simulator opens and AQE Field launches — dashboard, Knock tab, Reports with the follow-up queue, and the Field Bible with the Quiz button. That's the real app running. If a red error appears instead, copy the last ~15 lines back to me and I'll fix it.

A3 · Put it on your real iPhone

This is where you choose based on how you'll use it. Both start the same way — plug your iPhone into the Mac with a cable, open the project in Xcode:

open AQEField.xcodeproj

In Xcode: click the device dropdown at the top and pick your iPhone, then click Signing & Capabilities on the left, and under Team choose Add an Account… and sign in with your Apple ID. Then press the ▶ Play button. Now, the two options:

My recommendation: start free today to get it on your phone and use it for real. If it earns its place in your daily routine, pay the $99 for the Developer Program — that removes the 7-day expiry and unlocks TestFlight so the rest of the AQE crew can install it from an email link, no cable needed.

On the phone, the very first launch of a free-signed app shows "Untrusted Developer" — go to Settings → General → VPN & Device Management, tap your Apple ID, and tap Trust. One time only.

B You don't have a Mac

No Mac means no local build — but you're not stuck. Three realistic ways to get there, cheapest first:

Option 1 · Borrow a Mac for 30 minutes

The whole of Path A takes one sitting. If a friend, family member, or someone at the office has a Mac, borrow it — sign in with your Apple ID in the signing step so the app is tied to you, plug in your iPhone, and you're done. This is by far the least-expensive route.

Option 2 · Rent a Mac in the cloud

Services like MacStadium or MacinCloud give you a Mac you control from a Windows PC's browser, by the hour or month. You'd run all of Path A there — but the on-device install step still needs your physical iPhone connected, which a cloud Mac can't do. So cloud Macs are good for building and testing, and pair best with the paid Developer Program + TestFlight, which delivers the app to your phone over the internet (no cable). Realistically: ~$20–30 in cloud-Mac time plus the $99/yr Apple fee.

Option 3 · Hand it to an iOS developer (recommended if you want it hands-off)

The code is done and building — a freelance iOS developer's whole job here is signing and shipping, which is an hour or two of work, not a build-from-scratch. Point them at the repo and this exact instruction:

Hand this to the developer

"Repo: github.com/kurtxolsen/testing_1, app is in /AQEField. It's SwiftUI + XcodeGen (run ./build.sh). Please enroll me in the Apple Developer Program under my Apple ID, then get it onto my iPhone and set up TestFlight so I can add my sales team. It already builds — I just need it signed and shipped."

Meanwhile: you already have the web version on your home screen (the "AQE Field" icon you added in Safari). It covers the daily essentials — dashboard, knock tracking, follow-ups, the Bible, and stats — so you're not waiting empty-handed while the native app gets shipped.
